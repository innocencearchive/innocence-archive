# Navigation Flow for Wrongfully Convicted Americans Website

## Overview
This document outlines the navigation structure and user flows for the Wrongfully Convicted Americans website. The navigation is designed to be intuitive and focused on storytelling while enabling data exploration.

## Primary Navigation Structure

### Main Menu Items
1. **Home** - Landing page with featured content
2. **Browse Stories** - Search and filter all exoneree cases
3. **Explore Data** - Interactive visualizations and analysis tools
4. **Untold Stories** - Cases with little to no media coverage
5. **About** - Project information and methodology
6. **Contact** - Get in touch with the project team

### Secondary Navigation

#### Under "Browse Stories"
- By Name (A-Z)
- By Location (State/County)
- By Crime Type
- By Contributing Factor
- By Year of Exoneration
- By Time Served
- Advanced Search

#### Under "Explore Data"
- Geographic Patterns
- Contributing Factors Analysis
- Timeline View
- Demographic Analysis
- Crime Type Breakdown
- Justice System Insights

#### Under "About"
- Project Mission
- Methodology
- Data Sources
- Team
- Partners
- FAQ

## User Flows

### 1. Discovering Individual Stories
```
Home
  ↓
Browse Stories
  ↓
Apply Filters (optional)
  ↓
Browse Results
  ↓
Select Individual Case
  ↓
Story Detail Page
  ↓
Related Cases / Similar Stories
```

### 2. Finding Untold Stories
```
Home
  ↓
Untold Stories
  ↓
Filter by Location/Type (optional)
  ↓
Browse Untold Stories
  ↓
Select Individual Case
  ↓
Story Detail Page
  ↓
Contact (for journalists interested in covering the story)
```

### 3. Data Exploration
```
Home
  ↓
Explore Data
  ↓
Select Visualization Type
  ↓
Interact with Visualization
  ↓
Apply Filters (optional)
  ↓
View Insights
  ↓
Export Data (optional)
  ↓
Drill Down to Individual Cases (optional)
```

### 4. Geographic Exploration
```
Home
  ↓
Interactive Map
  ↓
Select Region (State/County)
  ↓
View Region Statistics
  ↓
Browse Cases in Region
  ↓
Select Individual Case
  ↓
Story Detail Page
```

### 5. Search Flow
```
Any Page (via search bar)
  ↓
Enter Search Terms
  ↓
View Search Results
  ↓
Filter Results (optional)
  ↓
Select Individual Case
  ↓
Story Detail Page
```

## Mobile Navigation

### Mobile Menu Structure
- Hamburger menu icon in header
- Expandable/collapsible sections
- Simplified navigation paths
- Persistent search icon
- Bottom navigation bar for key sections

### Mobile-Specific Flows
- Simplified filters with modal overlays
- Single-column layouts for all content
- Touch-optimized interactive elements
- Reduced data visualization complexity with option to view full version

## Cross-Linking Strategy

### Within Story Detail Pages
- Links to similar cases (by location, crime type, contributing factors)
- Links to geographic view showing the case location
- Links to related data insights

### Within Data Visualizations
- Links to relevant case examples
- Links to related visualizations
- Links to methodology explanations

### Within Untold Stories Section
- Links to similar cases that have received media attention
- Links to geographic patterns
- Links to journalist resources

## Breadcrumb Navigation
Implemented on deeper pages to show navigation path:

Example:
```
Home > Browse Stories > Illinois > Cook County > John Smith
```

## Search Functionality

### Global Search
- Available from all pages via persistent search bar
- Searches across names, locations, crime types, and case details
- Auto-suggest functionality for names and locations
- Recent searches saved for quick access

### Advanced Search
- Dedicated interface for complex queries
- Multiple filter combinations
- Save search functionality
- Export search results option

## Call-to-Action Placement

### Primary CTAs
- "Browse Stories" - Homepage hero section
- "Explore Your Area" - Homepage map section
- "Discover Untold Stories" - Homepage and about page

### Secondary CTAs
- "Share This Story" - Story detail pages
- "Export Data" - Data visualization pages
- "Contact for More Information" - Untold stories pages

## Footer Navigation
- About the Project
- Methodology
- Data Sources
- Privacy Policy
- Terms of Use
- Contact Information
- Social Media Links

## Accessibility Navigation Features
- Skip to content link
- Keyboard navigable menus
- ARIA landmarks for screen readers
- Focus management for interactive elements
- Alternative navigation paths for users with different abilities

This navigation structure prioritizes storytelling while providing clear paths to data exploration, ensuring users can easily find both individual stories and broader patterns in wrongful convictions.
