## Research Strategy

1. For each podcast:
   - Review episode listings and descriptions
   - Identify episodes featuring wrongfully convicted individuals
   - Document names, conviction details, and current status
   - Note any organizations mentioned that assisted with the case

2. For documentaries and books:
   - Create a list of all cases covered
   - Extract key details about each case
   - Identify any systemic issues highlighted

3. For news organizations:
   - Search archives for wrongful conviction coverage
   - Identify journalists who regularly cover this topic
   - Document any data projects or databases they maintain
