# Research Procedure for Wrongful Conviction Podcasts

This document outlines the systematic approach for researching podcasts about wrongful convictions and filling out the provided templates with relevant information.

## 1. Data Sources and Search Strategy

### Primary Data Sources:
1. **Podcast Platforms**:
   - Apple Podcasts
   - Spotify
   - Google Podcasts
   - Stitcher
   - Podchaser
   - Listen Notes

2. **Podcast Official Websites**:
   - Production company websites
   - Host websites
   - Network websites

3. **Social Media Platforms**:
   - Twitter/X
   - Instagram
   - Facebook
   - LinkedIn (for hosts/producers)

4. **News and Media Coverage**:
   - Articles about the podcasts
   - Interviews with hosts/producers
   - Reviews and critiques

5. **Legal and Advocacy Organizations**:
   - Innocence Project websites
   - Legal aid organizations
   - Criminal justice reform groups

## 2. Research Workflow

### Step 1: Basic Podcast Information Gathering
1. Search for the podcast name on podcast platforms and search engines
2. Identify and document:
   - Official website
   - Host information
   - Production company/network
   - Release years
   - Series type and format
   - Overall focus/theme
   - Episode list and structure

### Step 2: Episode Identification and Selection
1. Create a complete list of episodes for each podcast
2. Identify episodes specifically focused on wrongful convictions
3. Prioritize episodes based on:
   - Recency (newer episodes first)
   - Relevance to wrongful conviction topic
   - Availability of detailed information

### Step 3: Episode Data Collection
For each relevant episode:
1. Document basic information:
   - Episode number and title
   - Release date
   - Duration
   - Description/summary
2. Identify wrongfully convicted individuals featured
3. Extract key quotes, systemic issues, and policy recommendations
4. Note any additional resources mentioned

### Step 4: Individual Case Research
For each wrongfully convicted individual mentioned:
1. Document case details:
   - Full name
   - Case location
   - Conviction and exoneration years
   - Crime convicted of
   - Sentence and time served
   - Contributing factors to wrongful conviction
   - Current legal status
   - Organizations involved
2. Cross-reference with other sources to verify information
3. Note any discrepancies or additional information found

## 3. Data Collection Methods

### Method 1: Direct Information Extraction
- Extract information directly stated in podcast descriptions, show notes, and episode summaries
- Use official podcast websites and platforms for verified information

### Method 2: Web Search Triangulation
- Use search engines to find multiple sources discussing the podcast
- Cross-reference information across different sources
- Prioritize credible sources (news outlets, legal organizations, academic sources)

### Method 3: Social Media Mining
- Search for podcast and host accounts on social media platforms
- Extract information from posts, announcements, and interactions
- Look for audience discussions and reviews

### Method 4: API and Database Utilization
- Use podcast database APIs (where available)
- Search Twitter/X for mentions and discussions
- Utilize news databases for articles about the podcasts or cases

## 4. Template Population Process

### For Podcast List Template:
1. Fill in basic podcast information:
   - Title
   - Status (update to "In progress" or "Completed")
   - Overall focus
   - Podcast format
   - Link to official site
   - General notes about the podcast

### For Research Template:
1. Create a new file for each podcast using the research template structure
2. Fill in basic podcast information section
3. For each episode, create a section for wrongfully convicted individuals featured
4. Add podcast research notes with key quotes, systemic issues, and policy recommendations
5. Include links to additional resources

## 5. Quality Control Measures

1. **Verification**: Cross-check information across multiple sources
2. **Completeness Check**: Ensure all required fields have been addressed
3. **Consistency Review**: Maintain consistent formatting and terminology
4. **Source Documentation**: Include sources for all information
5. **Gap Identification**: Clearly mark information that could not be found

## 6. Deliverables Organization

1. Create a main directory for all research
2. Organize subdirectories by podcast name
3. For each podcast:
   - Create a main podcast information file
   - Create separate files for each episode (if extensive)
   - Compile all information into a structured format
4. Create a master index file linking to all podcast research

## 7. Special Considerations

1. **Limited Information**: For podcasts with minimal online presence, note limitations and focus on available data
2. **Ongoing Series**: For active podcasts, note the last episode included in research
3. **Multiple Cases**: For episodes featuring multiple cases, create separate entries for each individual
4. **Series Evolution**: Note any changes in format, focus, or hosts over time

This procedure provides a systematic approach to researching wrongful conviction podcasts and populating the templates with comprehensive, accurate information.
