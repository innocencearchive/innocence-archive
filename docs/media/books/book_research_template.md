# Book Research: Wrongful Conviction Media Sources

## Research Template for Each Book

For each book on wrongful convictions, we'll collect the following information:

### Basic Book Information
- **Title**: Full title of the book
- **Author(s)**: All authors/contributors
- **Publication Year**: Year of publication
- **Publisher**: Publishing company
- **Format**: Hardcover, paperback, e-book, audiobook
- **Focus/Theme**: Main topics covered (e.g., false confessions, DNA exonerations)
- **Key Statistics**: Notable statistics mentioned in the book

### Wrongfully Convicted Individuals Featured
For each individual mentioned:
- **Name**: Full name of the wrongfully convicted person
- **Case Location**: City, state, country
- **Conviction Year**: When they were convicted
- **Exoneration Year**: When they were exonerated (if applicable)
- **Crime Convicted Of**: What they were wrongfully convicted of
- **Sentence**: Original sentence received
- **Time Served**: How long they were incarcerated
- **Contributing Factors**: Factors that led to wrongful conviction (false confession, eyewitness misidentification, etc.)
- **Legal Status**: Current legal status (exonerated, released, pardoned, etc.)
- **Organizations Involved**: Any organizations that assisted with their case
- **Cross-Reference**: Whether they appear in the exoneree database

### Book Research Notes
- **Key Quotes**: Important quotes about wrongful conviction
- **Systemic Issues Identified**: Broader issues in the justice system discussed
- **Policy Recommendations**: Any suggested reforms or policy changes
- **Additional Resources**: Other sources mentioned that could be valuable

## Research Strategy
1. Begin with books that focus on multiple cases to maximize data collection
2. Prioritize recent publications for current information
3. Cross-reference individuals with the exoneree database
4. Document page numbers for key information to enable verification

## Integration Plan
- Create a structured CSV file for each book with all individuals mentioned
- Develop a master cross-reference spreadsheet linking exonerees to book mentions
- Prepare database schema updates if needed to accommodate book references
